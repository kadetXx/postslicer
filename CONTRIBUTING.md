# Contributing

Thanks for your interest in improving Slicey!

## Reporting bugs / requesting features

Open an issue with a clear description. For bugs, include steps to reproduce and your browser/OS.

## Making changes

1. Fork the repo and create a branch off `main`.
2. It's plain HTML/CSS/JS — no build step, just edit and refresh (`python3 -m http.server` to preview).
3. Test in a browser before opening a PR: upload a photo, try both slice counts, and confirm the download works.
4. Open a PR with a clear description of what changed and why.

By contributing, you agree your changes are licensed under the same AGPL-3.0 license as the rest of the project.
